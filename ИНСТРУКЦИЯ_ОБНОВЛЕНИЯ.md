# Инструкция по обновлению налогового калькулятора

## Где лежат важные данные

- Ссылка для клиентов и пароль для раздела «Параметры закона» хранятся локально в файле `.env`.
- Откройте `.env` в Блокноте и заполните значение после `LEGISLATION_PARAMETERS_PASSWORD=`. Не добавляйте этот файл на GitHub.
- Актуальная клиентская ссылка уже записана в `CLIENT_CALCULATOR_URL`.
- История всех изменений ведётся в файле `ИЗМЕНЕНИЯ.md`.

## Как обновлять калькулятор для аналитической записки

1. Сначала укажите, какие ставки, лимиты или тексты меняются, и приложите источник: закон, письмо ФНС или официальное разъяснение.
2. Обновление вносится в `index.html`. Для поиска старых значений используйте поиск по году, лимиту или ставке.
3. Одновременно обновите:
   - расчётные параметры и формулы;
   - тексты на экране;
   - окно «Как осуществляется расчёт?»;
   - примеры расчётов, если они используют изменённые величины;
   - запись в `ИЗМЕНЕНИЯ.md`.
4. Проверьте пограничные значения: ровно на лимите и на 1 ₽ выше него.
5. После проверки создайте отдельный Git-коммит с понятным сообщением, например: `feat: обновить калькулятор на параметры 2028 года`.
6. Только после подтверждения отправьте коммит на GitHub. GitHub Pages обновит клиентскую ссылку через несколько минут.

## Как пользоваться ссылкой для клиентов

1. Откройте `.env`.
2. Скопируйте значение после `CLIENT_CALCULATOR_URL=`.
3. Отправьте его клиенту. Это ссылка на калькулятор, а не на исходный код GitHub.

## Важно о пароле

Пароль из `.env` — только ваша локальная памятка. Калькулятор опубликован как статическая страница, поэтому пароль в разделе «Параметры закона» не является полноценной защитой: его нельзя использовать для хранения конфиденциальных данных. Не используйте там пароль от почты, банка или других сервисов.
